OPEN SOURCE ECOSYSTEM · A2A v1.0 & MCP SERVER (:18888)

전 세계 모든 에이전트와 소통하는 오픈 프로토콜

Hanson Mobile-Use AI는 /.well-known/agent-card.json (Google A2A v1.0) 및 /mcp/tools (Model Context Protocol) 표준 엔드포인트를 내장하고 있습니다. Claude Code, Codex, OpenClaw/Moltbook, LangGraph 등 어떤 외부 에이전트든 당신의 스마트폰과 직접 대화하고 피드백을 주고받을 수 있습니다.

# 1. 앱 [인스펙터/브리지] 탭의 256-bit 세션 토큰 설정 및 ADB 로컬 포트 포워딩 (기본 인증 강제) export ARTEMIS_TOKEN="<YOUR_256BIT_HEX_TOKEN>" adb forward tcp:18888 tcp:18888 # 2. A2A v1.0 표준 에이전트 카드 조회 & 병렬 BG 작업 위임 (X-Artemis-Token 필수) curl -s -H "X-Artemis-Token: $ARTEMIS_TOKEN" http://127.0.0.1:18888/.well-known/agent-card.json | jq . curl -X POST http://127.0.0.1:18888/a2a -H "Content-Type: application/json" -H "X-Artemis-Token: $ARTEMIS_TOKEN" \ -d '{"jsonrpc":"2.0","id":"1","method":"tasks/send","params":{"lane":"BG","prompt":"브라우저로 해커뉴스 최신 글 요약해줘"}}'
