## 4. Security & Zero-Dependency Guarantees

- **Zero External Pip Dependencies**: Every new Python module (`harness/`, `eval/`, `mcp/`) runs strictly on Python 3.9+ stdlib.
- **Fail-Closed Security Defaults**:
  - `OmnichannelRemoteBridge` rejects all requests when `allowed_sender_ids` is empty and compares tokens strictly via `hmac.compare_digest`.
  - Non-loopback plaintext `http://` targets are rejected across `hanson_secretary_sync.py` and `HansonIosPortalClient`.
  - `load_app_card(pkg)` enforces strict Android package regex validation (`^[A-Za-z][A-Za-z0-9_]*(\.[A-Za-z0-9_]+)+$`) blocking path traversal.
  - `hanson_trace_viewer.py` strictly escapes all HTML and allows only verified `data:image/(png|jpeg|webp);base64,...` URIs rendered in 0%-saturation grayscale.
- **Invariant Preservation**: `mcp/mobile_use_mcp_server.py` retains `SERVER_VERSION = "6.0.0"` and all 12 canonical MCP tools (`verify_python_security.py` passes 100%).
